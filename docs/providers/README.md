# Providers

Providers allow Elastic Machines to orchestrate machines across different clouds. A [YAML configuration file](../../README.md#yaml-configuration) controls which providers to use and their individual settings. Refer to each provider's documentation for provider specific configuration and setup.

Elastic Machines has built-in support for the following providers:

- [`azure-virtual-machine`](azure-virtual-machine.md)
- [`aws-instance`](aws-instance.md)
